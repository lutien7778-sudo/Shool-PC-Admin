# SchoolAdm — Централизованное администрирование парка школьных компьютеров

Кроссплатформенное графическое приложение на **Python 3 (PyQt6 + Paramiko)** для системного администратора школы и учителя информатики. Позволяет в один клик управлять компьютерным классом (20–30+ ПК) по протоколам **SSH** и **SFTP** без необходимости вручную подключаться к каждой машине.

## 🎯 Назначение и целевая аудитория

- **Целевая аудитория:** Учителя информатики, инженеры и системные администраторы учебных заведений.
- **Целевые клиентские ОС:**
  - **Альт Линукс** (Альт Образование, Альт Рабочая станция, СПТ)
  - **Astra Linux** (Common Edition, Special Edition «Смоленск» / «Воронеж»)
  - **Ubuntu** / **Debian**
  - Архитектуры: **x86_64** (Intel/AMD) и **ARM (aarch64)** (мобильные классы, планшеты, отечественные процессоры «Байкал», «Эльбрус» в режиме совместимости, Raspberry Pi).
- **Условия среды:** На всех клиентских ПК настроена единая учетная запись администратора (пользователь с правами `sudo` или `root`).

## ✨ Основные возможности

### 1. Блок подключения и профилей
- **Гибкий ввод IP-адресов:**
  - Одиночные адреса: `192.168.1.15`
  - Разделители: запятые, пробелы, переводы строк, точки с запятой
  - Полные диапазоны: `192.168.1.10-192.168.1.25`
  - Краткие диапазоны: `192.168.1.10-25`
  - Подсети CIDR: `192.168.1.0/28`
  - Автоматическая дедупликация и валидация.
- **Профили кабинетов (`profiles.json`):**
  - Быстрое переключение между кабинетами («Кабинет 1», «Кабинет 2», «Мобильный класс»).
  - Сохранение и удаление профилей с запоминанием IP, логина, порта и параметров привилегий.
- **Безопасность учетных данных:**
  - Скрытие/показ пароля по кнопке с пиктограммой 👁️.
  - Переключатель режима выполнения: **«От root»** / **«Через sudo»** (команды автоматически оборачиваются в `sudo -S` с безопасной передачей пароля через неинтерактивный stdin).

### 2. Поддержка дистрибутивов и архитектур
- Селекторы: **Alt Linux**, **Ubuntu**, **Debian**, **Astra Linux** и архитектур (**x86_64**, **ARM aarch64**).
- Адаптация команд обновления:
  - **Alt Linux:** `apt-get update && apt-get dist-upgrade -y`
  - **Ubuntu / Debian / Astra:** `export DEBIAN_FRONTEND=noninteractive; apt-get update && apt-get upgrade -y`

### 3. Набор действий
- **📡 Проверить доступность (Ping/SSH):**
  - Быстрое TCP-сканирование порта и SSH-проверка.
  - Автоматический сбор сведений о каждой машине: реальное имя хоста, версия ОС, архитектура CPU (`uname -m`), свободное место на корневом разделе и uptime.
- **🔄 Обновить систему на всех ПК:** Массовое обновление с защитным окном подтверждения.
- **📁 Передать файл:** Загрузка учебных материалов, скриптов или файлов заданий по SFTP с прогресс-баром.
- **🚀 Передать и запустить:** Передача файла, автоматическая установка прав `chmod +x` и запуск (синхронно или в фоновом режиме через `nohup`).
- **▶️ Запустить существующий файл:** Запуск программы или скрипта, уже находящегося на ПК, с передачей аргументов.
- **⌨️ Выполнить произвольную команду:** Ввод любой shell-команды с набором быстрых пресетов (`df -h`, `free -h`, `uptime`, `who`, `systemctl --failed`).
- **Быстрые действия питания:** **«Выключить все ПК»** (`poweroff`), **«Перезагрузить все ПК»** (`reboot`) с обязательным диалогом подтверждения.

### 4. Мониторинг и терминал логов
- **Интерактивная таблица хостов:**
  - Цветовые бейджи статусов (**🟢 Успешно**, **🟡 В процессе**, **🔴 Ошибка**, **⚪ Ожидание**).
  - Клик по строке компьютера мгновенно фильтрует терминал логов для выбранного ПК.
- **Консоль логов:**
  - Подсветка stdout (светлый текст), stderr (красный) и информационных сообщений (голубой).
  - Переключение фильтра: «Все компьютеры (Сводный)» или вывод конкретного ПК.
  - Функции копирования, очистки и экспорта в файл `.txt`.

### 5. Многопоточность и надежность
- Построен на связке `QThread` + `concurrent.futures.ThreadPoolExecutor`.
- Графический интерфейс никогда не зависает — параллельная работа с 20–30 машинами происходит в фоне.
- Таймаут соединения: 6 секунд (предотвращает зависания на выключенных ПК).
- Кнопка **«⏹️ Остановить»** для прерывания текущей операции.

## 🚀 Установка и запуск

### 1. Требования к системе
- Python **3.9+** (рекомендуется Python 3.10–3.12/3.13/3.15).
- Доступ по сети к клиентским ПК по порту 22 (SSH).

### 2. Установка зависимостей

#### На Linux (Альт Линукс, Astra Linux, Ubuntu, Debian):
```bash
# Клонируйте или скопируйте репозиторий
cd ShoolAdm

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

#### На Windows:
```powershell
# В PowerShell в папке проекта:
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. Запуск приложения

```bash
# Linux
source .venv/bin/activate
python main.py

# Windows
.\.venv\Scripts\python.exe main.py
```

### 4. Запуск автоматических тестов

```bash
python -m unittest tests/test_core.py
```

## 🛠️ Настройка клиентских ПК (Альт Линукс, Astra Linux, Ubuntu)

Для того чтобы приложение могло централизованно управлять компьютерами класса, на клиентских ПК должны быть выполнены базовые условия:

1. **Включена служба SSH-сервера:**
   ```bash
   # Альт Линукс:
   systemctl enable --now sshd

   # Ubuntu / Debian / Astra Linux:
   sudo systemctl enable --now ssh
   ```

2. **Права администратора:**
   - Если используется пользователь с `sudo`, убедитесь, что учетная запись входит в группу `wheel` (Альт Линукс) или `sudo` (Ubuntu/Debian/Astra).
   - При желании настроить запуск без постоянного ввода пароля для `sudo`:
     ```bash
     echo "teacher ALL=(ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/teacher
     ```

3. **Брандмауэр:**
   - Убедитесь, что порт `22/tcp` открыт в школьной подсети:
     ```bash
     # UFW (Ubuntu/Astra):
     sudo ufw allow from 192.168.0.0/16 to any port 22 proto tcp
     ```

## 🛡️ Безопасность

- Приложение не сохраняет пароли во внешние облачные сервисы. Файл `profiles.json` хранится локально на компьютере учителя/администратора.
- При выполнении потенциально опасных массовых операций (перезагрузка, выключение, запуск скриптов, обновление) всегда запрашивается явное подтверждение через диалоговое окно.
